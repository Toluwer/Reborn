About

Reborn v1.0 — single-file HTML concept. Every CSS variable maps to an entry in the Luau theme table, each row becomes a Frame with UICorner and UIStroke, and the sidebar is a ScrollingFrame with a UIListLayout. Near-black surfaces, hairline borders, one accent color — nothing else.
